# 극한 체험! 이상한 키오스크 월드

초등학생이 불친절한 키오스크를 체험하며 배리어프리 설계의 필요성을 배우는 정적 웹앱입니다.
Vercel에서는 별도 경로 `/bias`에 알파코 : 블랙박스 체험 앱도 함께 배포됩니다.

## 체험 구성

- 3초 뒤 사라지는 주문 키오스크
- 콩알 버튼 키오스크
- 외계어 메뉴 키오스크
- 흐릿흐릿 색깔 키오스크
- 소리만 알려주는 번호표 키오스크

각 체험은 `어려운 모드`와 `개선 모드`를 비교할 수 있게 구성되어 있습니다.

## 별도 웹앱

- `/bias`: 카메라 기반 인공지능 얼굴 분석처럼 보이는 알파코 : 블랙박스 편향 체험 시뮬레이터

## 로컬 확인

```bash
npm run check
python3 -m http.server 3000
```

브라우저에서 `http://127.0.0.1:3000`을 열면 됩니다.
로컬 기본 서버에서는 Vercel rewrite가 적용되지 않으므로 `/bias.html`로 확인합니다.

## Vercel 배포

정적 HTML/CSS/JS 앱이므로 Vercel에서 GitHub 저장소를 연결하면 바로 배포할 수 있습니다.
`vercel.json`에는 확장자 없는 URL을 위한 `cleanUrls`와 `/bias` rewrite를 포함했습니다.
